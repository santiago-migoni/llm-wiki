# Inventario de integraciones y capacidades de investigación de `obsidian-second-brain`

**Alcance:** inspección estática de `.repos/obsidian-second-brain/integrations/**` y `.repos/obsidian-second-brain/scripts/research/**` en el checkout local. Se revisaron 22 archivos de integración y 40 archivos de investigación (incluidos inicializadores y módulos de fuentes). Sin ejecutar scripts, MCP, plugin de Obsidian, pruebas, ni llamadas de red. Esto describe implementación observada; no constituye auditoría de seguridad ni aprobación de arquitectura.

## Discrepancias y lecturas documentales

- MCP: el README enumera 10 operaciones de datos/curator/skills, mientras el servidor registra 12; faltan en la tabla `obsidian_replace_text` y `obsidian_move_note`. La sección de bookkeeping sí nombra ambas. El README también conserva lenguaje de Inbox-only y checklist de tres herramientas que no describe la interfaz actual completa.
- La documentación del MCP afirma protocolo live-test validado y marca Hermes como no probado; aquí no se ejecutó el servidor ni se verificó esa evidencia histórica.
- Telegram README tiene descripción de alto nivel, setup y formatos; el código implementa allowlist cerrada por defecto, almacenamiento de estado, fichero local y rutas de procesamiento. `handle_move` contradice la lectura literal de “nada se borra”: no borra notas, pero sí mueve/reubica el bloque y adjunto.
- Plugin Obsidian documenta y codifica un linter read-only. Es una utilidad aparte, no dependencia del toolkit. Sus reglas viven en segunda implementación junto a reglas de vault/MCP.
- Los módulos `devto.py` y `lobsters.py` son adaptadores presentes pero el constructor de fuentes de `/research` no los usa. Los extras Brave/Tavily sí se activan condicionalmente por clave.
- Los nombres `/research`, `/research-deep`, `/x-pulse`, `/x-read`, `/youtube`, `/podcast` y `/notebooklm` corresponden a comandos/playbooks del agente más scripts Python. La presencia del script por sí sola no implementa la experiencia conversacional ni la propagación de notas.

## Conteo y rutas cubiertas

- Integraciones: 22 archivos bajo `.repos/obsidian-second-brain/integrations/` (servidor MCP, plugin AI-First Lint, bot Telegram, ejemplos/configuración/tests incluidos).
- Investigación: 40 archivos bajo `.repos/obsidian-second-brain/scripts/research/` (7 entrypoints, librerías comunes y fuentes). En `lib/sources/` hay 12 adaptadores: 10 fuentes activas únicas posibles entre selecciones/modos de `/research` (6 default, 2 extras con clave y 2 adicionales académicas) y 2 presentes pero sin caller en el agregado (`devto`, `lobsters`).
- Las fuentes permanecen intactas; este anexo forma parte del inventario documental del proyecto.
